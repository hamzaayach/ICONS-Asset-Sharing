# ICONS Asset Sharing

Public image host for the Shopify Icons team. Google Slides and Docs can only import images from public URLs, and Shopify's Google Workspace and Slack both block public link sharing, so this repo is the bridge.

**Everything here is public on the internet.** Only put things here that could be seen by anyone:

- Reference renders, mockups, AI concept art
- Logos and marks that are already public
- Photos we own and are cleared to share

Never put here: contracts, budgets, decks, unreleased talent content, anything with a talent's likeness before their reps have approved it, guest lists, or anything marked confidential.

## How to use

1. Add the image to a project folder (drag and drop on github.com works), or ask Alfie to do it.
2. The public URL is:

   `https://raw.githubusercontent.com/hamzaayach/ICONS-Asset-Sharing/main/<folder>/<file>`

3. In Slides or Docs: Insert > Image > By URL, paste the link. The file is copied into the deck, so the repo copy can be deleted later if needed.

## Conventions

- One folder per project, named by Vault code and partner, e.g. `brand-1071-lando-quadrant/`
- Subfolders by deliverable, e.g. `car-options-deck/`
- JPEG at 1800px wide, quality 90, is plenty for a slide. Keep files under 5 MB.
- Lowercase, hyphenated filenames.
